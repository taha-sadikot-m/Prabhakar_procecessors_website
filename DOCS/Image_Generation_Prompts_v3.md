## HOW TO USE THIS DOCUMENT

Generate images in the exact order listed. Each prompt is **fully self-contained** — copy the entire block between the triple backticks, paste directly into your AI image generator. Nothing is left out — size, style, composition, background, ghost motif, lighting, colours — it's all inside each prompt.

**Client requirement (mandatory — built into every prompt):**
> Do not use only traditional fabric images. Use a mix of textile products such as sarees, cotton fabrics, dress materials, printed fabrics, and other modern textile products.

This variety is built into every prompt below. Each section features a different textile type so the website as a whole showcases the full range of what Prabhakar Processors handles.

**Midjourney users:** Add `--ar 16:9` (desktop) or `--ar 9:16` (mobile) at the end of the prompt.
